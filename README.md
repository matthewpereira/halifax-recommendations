# Halifax Recommendations

Static photo gallery for a friend. No build step: `index.html`, `style.css`, `lightbox.js`, `photos/`.

Preview locally: `python3 -m http.server 8000` then open http://localhost:8000

Deploy: push to GitHub, Settings > Pages > Deploy from branch `main`, folder `/`.

Left out of the source PDF (warm-season only): Halifax Public Gardens, The Grand Parade, the Public Gardens dairy bar tip, Stillwell Beer Garden, the "July/August is ideal" line.
